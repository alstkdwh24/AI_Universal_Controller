AI 유니버설 컨트롤러 프로젝트 명세서

## 프로젝트 개요
AI 유니버설 컨트롤러는 다양한 AI 기능을 통합하여 제공하는 포트폴리오 프로젝트입니다.
개발자: 민상
기술 스택: FastAPI, Python, ChromaDB, Gemini AI, Spring Boot, React

## 주요 기능
- RAG(검색 증강 생성) 기반 AI 챗봇
- 구글 검색을 활용한 실시간 정보 조회
- 벡터 데이터베이스를 활용한 문서 검색

## 백엔드
- FastAPI로 REST API 구현
- ChromaDB로 벡터 저장
- Gemini 2.5-flash 모델 사용

## 프론트엔드
- React 기반 UI
